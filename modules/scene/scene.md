Scene Module
============

@namespace lagrange::scene

@defgroup module-scene Scene Module
@brief Scene graph data structures.

- Scene graphs with meshes, materials, lights, cameras, and node hierarchies: [Scene](@ref lagrange::scene::Scene).
- Simple scenes for instanced meshes: [SimpleScene](@ref lagrange::scene::SimpleScene).
- Mesh conversion: [mesh_to_scene](@ref lagrange::scene::mesh_to_scene), [mesh_to_simple_scene](@ref lagrange::scene::mesh_to_simple_scene).
- Scene bounds: [simple_scene_bbox](@ref lagrange::scene::simple_scene_bbox).
- Scene extensions: [Extensions](@ref lagrange::scene::Extensions).
