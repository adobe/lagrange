Texproc Module
============

@namespace lagrange::texproc

@defgroup module-texproc Texproc Module
@brief Texture-space processing utilities.

- Filter, stitch, and composite mesh textures: [texture_filtering](@ref lagrange::texproc::texture_filtering), [texture_stitching](@ref lagrange::texproc::texture_stitching), [texture_compositing](@ref lagrange::texproc::texture_compositing).
- Rasterize multi-view renders into textures: [TextureRasterizer](@ref lagrange::texproc::TextureRasterizer).
- Extend textures geodesically beyond UV charts and generate position maps: [geodesic_dilation](@ref lagrange::texproc::geodesic_dilation).
- Extract mesh geometry using texture alpha masks: [extract_mesh_with_alpha_mask](@ref lagrange::texproc::extract_mesh_with_alpha_mask).
